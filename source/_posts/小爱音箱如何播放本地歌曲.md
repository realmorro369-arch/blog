第一次成功推流

```python
import asyncio, json
from aiohttp import ClientSession
from miservice import MiAccount, MiNAService

TOKEN = {
    "userId": "<USER_ID>",
    "deviceId": "<登录设备ID>",
    "micoapi": ["<ssecurity>", "<service_token>"],
}

async def main():
    with open("/tmp/.mi.token", "w") as f:
        json.dump(TOKEN, f)
    session = ClientSession()
    account = MiAccount(session, "", "", token_store="/tmp/.mi.token")
    mina = MiNAService(account)

    # 设备列表里能直接看到小爱音箱
    devices = await mina.device_list()

    # 推本地歌曲 URL 给音箱
    ret = await mina.play_by_music_url(
        "<音箱deviceID>",
        "http://192.168.1.93:58090/music/三人游.mp3",
        _type=1,
        audio_id="1582971365183456177",
    )
    print(json.dumps(ret, ensure_ascii=False))

asyncio.run(main())
```

返回：

```json
{"code": 0, "message": "Msg has been successfully proxy to the device ...", "data": {"code": 0}}
```

再查播放状态：

```json
{"status": 1, "volume": 29, "play_song_detail": {"audio_id": "1582971365183456177", "position": 3970, "duration": 237453}}
```

`duration: 237453ms` —— 正是《三人游》3 分 57 秒的完整长度。**NAS 里的歌，真的从小爱音箱里唱出来了。**

### 10.2 坑：invalid admin

第一次推流失败，报错：

```json
{"code": 1, "message": "invalid admin", "data": null}
```

排查发现，MICO 设备列表里同一个音箱有两个 ID：

- `deviceID`：形如 `b4a0b11b-d544-40b2-aa25-55dc6b1a8596` 的 UUID；
- `miotDID`：形如 `502445264` 的数字 DID。

`remote/ubus` 接口要的是 **UUID（deviceID）**，我用成了 `miotDID`，于是返回 `invalid admin`。换成 UUID 后一切正常。

**经验**：遇到这种“权限”类报错，先检查是不是把设备的两种 ID 用混了。

## 十一、监听音箱说了什么

推流成功只是第一步，还要知道用户对小爱说了什么。

### 坑：nlp_result_get 失效

xiaomusic 内部用 `miservice` 的 `get_latest_ask()` 拉对话记录，它调用 `remote/ubus` 的 `nlp_result_get`。在 L05B 的当前固件上直接报：

```
KeyError('info')
```

说明这个型号/固件不走这条链路。翻 xiaomusic 源码 `conversation.py`，发现 L05B 默认走的是另一个接口：

```
https://userprofile.mina.mi.com/device_profile/v2/conversation
    ?source=dialogu&hardware=L05B&timestamp=<毫秒>&limit=3
```

请求时带上 cookie：

```python
cookies = {
    "userId": user_id,
    "serviceToken": service_token,
    "deviceId": DEVICE_ID,
}
```

返回的 `data` 是个 JSON 字符串，`records[].query` 就是用户对小爱说的原话：

```json
{"code": 0, "data": "{\"records\":[{\"query\":\"本地播放三人游\",\"requestId\":\"3c854419...\",\"time\":1786357147643}]}"}
```

至此，闭环的最后一块拼图齐了：**听得到、推得出、验证得了**。

## 十二、语音点歌守护进程

### 坑：试听版抢播

把监听和推流串起来后，出现了一个非常经典的竞态：

> 对小爱说“本地播放三人游”，音箱先秒开自己的 QQ 音乐试听版（30 秒），我们的推送指令晚到 1~2 秒，**抢不过它**。

xiaomusic 源码里其实已经给了答案，播放前先 `force_stop_xiaoai()`：

```python
async def force_stop_xiaoai(self, device_id):
    await self.mina_service.player_pause(device_id)   # 先暂停
    await self.stop_if_xiaoai_is_playing(device_id)   # 再停止
```

照抄这个思路，并且做得更稳：

1. 检测到播放口令后，**先 pause，再 stop**，把音箱的播放权抢回来；
2. 停顿 0.6 秒，推送本地歌曲；
3. 4 秒后查询播放状态，校验 `status == 1`、`audio_id` 匹配、`duration >= 60s`（试听版只有 30 秒）；
4. 校验不过就再强制停止、重推一次。

### 完整代码

最终跑在生产环境的就是下面这个脚本（敏感值已用占位符替换），纯 Python 标准库实现，零第三方依赖：

```python
#!/usr/bin/env python3
"""小爱音箱语音点歌监听程序

轮询音箱的对话记录，识别“播放歌曲X / 本地播放 / 放歌”等口令，
把 NAS 本地音乐推给音箱播放。
"""

import json
import logging
import os
import random
import re
import sys
import time
import urllib.parse
import urllib.request

MUSIC_DIR = "/vol1/1000/music"
HA_AUTH = (
    "/vol1/@appshare/Home-Assistant/config/.storage/xiaomi_miot/"
    "auth-<USER_ID>-cn-micoapi.json"
)
DEVICE_ID = "<音箱的deviceID>"
BASE_URL = "http://192.168.1.93:58090"
UA = (
    "MiHome/6.0.103 (com.xiaomi.mihome; build:6.0.103.1; iOS 14.4.0) "
    "Alamofire/6.0.103 MICO/iOSApp/appStore/6.0.103"
)
AUDIO_ID = "1582971365183456177"
POLL_SEC = 1.0

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
    handlers=[
        logging.StreamHandler(sys.stdout),
        logging.FileHandler("/vol1/1000/docker/xiaomusic/voice_daemon.log"),
    ],
)
log = logging.getLogger("voice")

seen_requests = set()
current_song = None

PREFIXES = [
    "播放本地歌曲",
    "本地播放歌曲",
    "播放本地音乐",
    "播放歌曲",
    "放歌曲",
    "播放歌单",
    "播放列表",
    "本地播放",
    "播放音乐",
    "放音乐",
    "放歌",
    "播放",
]
BARE_PLAY = {"放歌", "本地播放", "播放音乐", "放音乐", "随机播放", "来点音乐", "放个歌", "来首歌"}
STOP_CMDS = {"停止", "停止播放", "别放了", "别唱了", "停一下", "关机"}
PAUSE_CMDS = {"暂停", "先暂停"}
RESUME_CMDS = {"继续", "继续播放", "接着放", "继续唱"}
NEXT_CMDS = {"下一首", "换一首", "切歌", "换歌"}


def load_token():
    with open(HA_AUTH, encoding="utf-8") as f:
        data = json.load(f)["data"]
    return str(data["user_id"]), data["service_token"]


def http_json(url, data=None, cookies=None):
    headers = {"User-Agent": UA}
    if cookies:
        headers["Cookie"] = "; ".join(f"{k}={v}" for k, v in cookies.items())
    if data is not None:
        body = urllib.parse.urlencode(data).encode()
        req = urllib.request.Request(url, data=body, headers=headers)
    else:
        req = urllib.request.Request(url, headers=headers)
    with urllib.request.urlopen(req, timeout=15) as r:
        return json.loads(r.read().decode("utf-8", "replace"))


def get_conversation(user_id, service_token):
    cookies = {
        "userId": user_id,
        "serviceToken": service_token,
        "deviceId": DEVICE_ID,
    }
    url = (
        "https://userprofile.mina.mi.com/device_profile/v2/conversation"
        f"?source=dialogu&hardware=L05B&timestamp={int(time.time()*1000)}&limit=3"
    )
    resp = http_json(url, cookies=cookies)
    if resp.get("code") != 0:
        raise RuntimeError(f"conversation code={resp.get('code')}")
    data = json.loads(resp["data"])
    return data.get("records", [])


def list_songs():
    songs = []
    for root, _dirs, files in os.walk(MUSIC_DIR):
        for fn in files:
            low = fn.lower()
            if low.endswith((".mp3", ".flac", ".wav", ".m4a", ".ogg", ".aac")):
                songs.append(os.path.join(root, fn))
    return songs


def normalize(text):
    return re.sub(r"[\s，。！？,.!?~～、\"'“”‘’：:]", "", text or "")


def parse_command(query):
    q = normalize(query)
    if not q:
        return None
    if q in BARE_PLAY:
        return ("play_bare", "")
    if any(q.startswith(c) or q == c for c in STOP_CMDS):
        return ("stop", "")
    if any(q.startswith(c) or q == c for c in PAUSE_CMDS):
        return ("pause", "")
    if any(q.startswith(c) or q == c for c in RESUME_CMDS):
        return ("resume", "")
    if any(q.startswith(c) for c in NEXT_CMDS):
        return ("next", "")
    for pre in PREFIXES:
        if q.startswith(pre):
            name = q[len(pre):].strip()
            if name:
                return ("play", name)
            return ("play_bare", "")
    return None


def find_song(name, songs):
    target = normalize(name)
    if not target:
        return None
    # exact base-name match first
    exact = [s for s in songs if normalize(os.path.splitext(os.path.basename(s))[0]) == target]
    if exact:
        return exact[0]
    # substring match
    subs = [s for s in songs if target in normalize(os.path.basename(s))]
    if subs:
        return subs[0]
    return None


def song_url(path):
    rel = os.path.relpath(path, MUSIC_DIR).replace("\\", "/")
    parts = [urllib.parse.quote(p) for p in rel.split("/")]
    return f"{BASE_URL}/music/{'/'.join(parts)}"


def ubus(user_id, service_token, method, path, message):
    cookies = {"userId": user_id, "serviceToken": service_token}
    data = {
        "deviceId": DEVICE_ID,
        "message": json.dumps(message),
        "method": method,
        "path": path,
        "requestId": "app_ios_" + "".join(
            random.sample("abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789", 30)
        ),
    }
    return http_json(
        "https://api2.mina.mi.com/remote/ubus", data=data, cookies=cookies
    )


def play_song(user_id, service_token, path):
    url = song_url(path)
    music = {
        "payload": {
            "audio_type": "MUSIC",
            "audio_items": [
                {
                    "item_id": {
                        "audio_id": AUDIO_ID,
                        "cp": {
                            "album_id": "-1",
                            "episode_index": 0,
                            "id": "355454500",
                            "name": "xiaowei",
                        },
                    },
                    "stream": {"url": url},
                }
            ],
            "list_params": {
                "listId": "-1",
                "loadmore_offset": 0,
                "origin": "xiaowei",
                "type": "MUSIC",
            },
        },
        "play_behavior": "REPLACE_ALL",
    }
    message = {"startaudioid": AUDIO_ID, "music": json.dumps(music)}
    return ubus(user_id, service_token, "player_play_music", "mediaplayer", message)


def force_stop(user_id, service_token):
    """先暂停再停止，抢回音箱的播放权"""
    ubus(
        user_id,
        service_token,
        "player_play_operation",
        "mediaplayer",
        {"action": "pause", "media": "app_ios"},
    )
    time.sleep(0.3)
    ubus(
        user_id,
        service_token,
        "player_play_operation",
        "mediaplayer",
        {"action": "stop", "media": "app_ios"},
    )


def get_status(user_id, service_token):
    ret = ubus(
        user_id,
        service_token,
        "player_get_play_status",
        "mediaplayer",
        {"media": "app_ios"},
    )
    try:
        return json.loads(ret.get("data", {}).get("info", "{}"))
    except Exception:
        return {}


def play_with_override(user_id, service_token, path):
    """强制停止后推送本地歌曲，并校验是否真的生效，最多重试2次"""
    for attempt in range(2):
        force_stop(user_id, service_token)
        time.sleep(0.6)
        ret = play_song(user_id, service_token, path)
        log.info("推送尝试%d: %s -> %s", attempt + 1, os.path.basename(path), ret)
        time.sleep(4)
        info = get_status(user_id, service_token)
        aid = (info.get("play_song_detail") or {}).get("audio_id", "")
        dur = (info.get("play_song_detail") or {}).get("duration", 0)
        ok = info.get("status") == 1 and aid == AUDIO_ID and dur >= 60000
        if ok:
            log.info("校验通过: audio_id=%s duration=%sms", aid, dur)
            return True
        log.warning(
            "校验未通过(第%d次): status=%s audio_id=%s duration=%sms",
            attempt + 1,
            info.get("status"),
            aid,
            dur,
        )
    return False


def tts(user_id, service_token, text):
    return ubus(user_id, service_token, "text_to_speech", "mibrain", {"text": text})


def stop(user_id, service_token):
    return ubus(
        user_id,
        service_token,
        "player_play_operation",
        "mediaplayer",
        {"action": "stop", "media": "app_ios"},
    )


def pause(user_id, service_token):
    return ubus(
        user_id,
        service_token,
        "player_play_operation",
        "mediaplayer",
        {"action": "pause", "media": "app_ios"},
    )


def resume(user_id, service_token):
    return ubus(
        user_id,
        service_token,
        "player_play_operation",
        "mediaplayer",
        {"action": "play", "media": "app_ios"},
    )


def handle(cmd, arg, user_id, service_token, songs):
    global current_song
    kind = cmd
    if kind == "play_bare":
        mp3s = [s for s in songs if s.lower().endswith(".mp3")] or songs
        if not mp3s:
            tts(user_id, service_token, "本地没有可播放的音乐")
            return
        pick = random.choice(mp3s)
        current_song = pick
        play_with_override(user_id, service_token, pick)
        log.info("播放随机歌曲: %s", os.path.basename(pick))
        return
    if kind == "play":
        path = find_song(arg, songs)
        if not path:
            tts(user_id, service_token, f"没找到歌曲{arg}，换个名字试试")
            log.info("未找到歌曲: %s", arg)
            return
        if path.lower().endswith(".flac"):
            alt = os.path.splitext(path)[0] + ".mp3"
            if os.path.isfile(alt):
                path = alt
            else:
                tts(user_id, service_token, "这首歌是无损格式，音箱不支持，换首MP3吧")
                log.info("FLAC不支持，跳过: %s", path)
                return
        current_song = path
        play_with_override(user_id, service_token, path)
        log.info("播放歌曲: %s", os.path.basename(path))
        return
    if kind == "stop":
        log.info("停止: %s", stop(user_id, service_token))
        return
    if kind == "pause":
        log.info("暂停: %s", pause(user_id, service_token))
        return
    if kind == "resume":
        log.info("继续: %s", resume(user_id, service_token))
        return
    if kind == "next":
        mp3s = [s for s in songs if s.lower().endswith(".mp3")] or songs
        if not mp3s:
            return
        pick = random.choice([s for s in mp3s if s != current_song] or mp3s)
        current_song = pick
        log.info("下一首: %s", os.path.basename(pick))
        play_with_override(user_id, service_token, pick)
        return


def main():
    songs = list_songs()
    log.info("启动，共 %d 首本地歌曲", len(songs))
    initialized = False
    while True:
        try:
            user_id, service_token = load_token()
            records = get_conversation(user_id, service_token)
            if not initialized:
                # 首次启动：跳过历史记录，只处理之后的语音口令
                for rec in records:
                    rid = rec.get("requestId", "")
                    if rid:
                        seen_requests.add(rid)
                initialized = True
                log.info("已忽略 %d 条历史记录", len(records))
                time.sleep(POLL_SEC)
                continue
            for rec in records:
                rid = rec.get("requestId", "")
                query = rec.get("query", "") or ""
                if not rid or rid in seen_requests:
                    continue
                seen_requests.add(rid)
                if len(seen_requests) > 500:
                    seen_requests.clear()
                cmd = parse_command(query)
                if cmd:
                    log.info("识别到口令: %r -> %s", query, cmd)
                    handle(cmd[0], cmd[1], user_id, service_token, songs)
        except Exception as e:
            log.warning("轮询异常: %r", e)
        time.sleep(POLL_SEC)


if __name__ == "__main__":
    main()
```

几个实现要点：

- **会话保鲜**：每次轮询都重新读 HA 的 `auth-<USER_ID>-cn-micoapi.json`，只要 HA 的 `xiaomi_miot` 集成还活着，token 就会自动续期，守护进程永远不失效；
- **去重**：按 `requestId` 去重，只处理新口令，重启服务也不会重放历史；
- **模糊匹配**：歌名先精确匹配文件名，再子串匹配，说“三人游”“七里香”都能命中；
- **FLAC 兜底**：L05B 硬件不支持 FLAC，命中 FLAC 时提示用户换 MP3，而不是卡死。

## 十三、部署与开机自启

把脚本放到 NAS 上，然后用 systemd 托管：

```ini
[Unit]
Description=Xiaomi speaker voice music daemon
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=morro
ExecStart=/usr/bin/python3 /vol1/1000/docker/xiaomusic/voice_daemon.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo cp xiaomusic-voice.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now xiaomusic-voice
```

`Restart=always` 保证进程挂了自动拉起，`enable` 保证 NAS 重启后自启。

## 十五、总结与避坑清单

1. **先画架构再动手**：这次最大的弯路（Music Assistant）就是没想清楚用户路径就装了；
2. **读源码比瞎猜快**：`invalid admin`、`KeyError('info')`、试听版抢播，全部是翻 `xiaomusic` 和 `python-miservice` 的源码找到的答案；
3. **会话复用**：小米云 API 认 token 不认密码，HA 里存着的会话就是门票；
4. **设备有两个 ID**：ubus 用 UUID（deviceID），别用 miotDID；
5. **先停再推**：抢不过音箱自带的音乐服务，就先把它停掉；
6. **FLAC**：L05B 不支持无损，用 MP3 或转码；
7. **安全**：`58090` 这类管理端口不要直接暴露公网，小米会话文件不要外泄。
